# 部署上线文档模板

以执行时的时区记录时间。填入实际数据，无法证实的项标记为未测、待完成或不适用。

- **结果与访问入口**。项目名称、环境、域名、发布时间、提交或版本及上线状态。
- **发布与运行**。实际使用的面板接入路径、构建方式和发布包校验、安装目录、进程服务名、监听端口、自启状态与日志路径。
- **数据库**。来源类型、目标库或路径、快照时间、迁移方式、完整性结果、可公开的记录计数、备份与保留位置。
- **域名和证书**。DNS、代理目标、证书覆盖范围和到期日、HTTP 跳转状态。按需区分面板和站点。
- **验证记录**。每项包含时间、目标、预期与实际结果。覆盖公网首页、静态资源、状态接口和发布版本、数据库与服务状态。记录未测功能及原因。
- **变更与回滚**。变更的服务、站点配置、备份位置、恢复顺序和复验方式。若有切换后写入，注明恢复数据库前需处理的数据。
- **遗留事项**。未完成、失败或需用户操作的步骤，写明当前状态和下一步。

使用脱敏证据。面板地址只保留运维需要的部分，省略安全入口、会话参数、账号口令、证书私钥和令牌。截图只保留可安全分享的页面。
